## 🌌 ╬══─ [ 🛠️ Cyber Security & Penetration Testing Tools ] ─══╬

> **تحذير أمني:** جميع الأدوات المذكورة أدناه يتم تشغيلها واختبارها داخل بيئات معزولة (Sandboxed / Termux) لأغراض فحص الثغرات والتعليم الأمني فقط.

### 🔍 1. أدوات الفحص والاستطلاع (Reconnaissance & Scanning)
* 🌐 **Nmap & Masscan:** لفحص الشبكات، المنافذ المفتوحة، وتحديد الخدمات النشطة وجدران الحماية.
* 🛡️ **Nikto:** لفحص خوادم الويب واكتشاف الإعدادات الخاطئة والثغرات المعروفة.
* 🛰️ **Subfinder / Amass:** لجمع النطاقات الفرعية (Subdomains) وتوسيع نطاق الهدف.

### 💀 2. فحص واستغلال ثغرات الويب (Web App Exploitation)
* 💉 **SQLMap:** الأداة الأقوى للفحص التلقائي واستغلال ثغرات حقن قواعد البيانات (SQL Injection).
* 📂 **Dirsearch / Gobuster:** لعمل brute-force واكتشاف الملفات والمجلدات المخفية على السيرفرات.
* 🔓 **Burp Suite:** لاعتراض وتحليل حزم البيانات (HTTP Requests) وتعديلها يدوياً.

### 📱 3. بيئات التحكم والاختراق المتقدم (Exploitation Frameworks)
* 🤖 **RouterSploit:** لفحص واستغلال ثغرات أجهزة الراوتر والـ IoT Devices.
* 🐚 **Metasploit Framework:** لتطوير وتطبيق أكواد الاستغلال (Payloads) واختراق الأنظمة المفتوحة.
* 📟 **Termux Environment:** البيئة الأساسية لتشغيل كافة سكربتات الأتمتة والاختراق مباشرة من الهاتف.
